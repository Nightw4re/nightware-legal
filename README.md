# Nightware Games – Legal Information

Welcome to the official legal information repository
for Nightware Games, an independent game development studio.

This repository contains privacy policies, data deletion
instructions, and other legal documents for our games.

## Our Games

### Foundrysteed

Foundrysteed is a medieval settlement management game
for Android.

Players can build and expand their settlements, manage
workers, gather resources, develop production chains,
and research new technologies.
